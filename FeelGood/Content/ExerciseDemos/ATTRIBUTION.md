## House-drawn frames (original, gender-neutral figure)

The 15 glossary exercises with no Workout Guide equivalent frame set were
drawn fresh rather than adapted from the above source. These are original
poses, not traced or edited from Everkinetic/Workout Guide art, so they carry
no CC BY-SA obligation — credited here only as a style note:

- Line technique (single continuous white outline, transparent background,
  numbered-frame flipbook) inspired by Bryl Lim's Workout Guide, itself
  building on Everkinetic.
- Figure drawn gender-neutral for this app, without Workout Guide's
  muscular male-presenting default body.

## Unused files

This directory also ships PNG frame sets for ~289 other Workout Guide
exercises that no glossary entry currently references (`ExerciseDemo.swift`
only looks up files by glossary id). They're the same CC BY-SA 4.0 source and
would need this same attribution treatment if any of them get wired up —
until then they're just unreferenced weight in the app bundle and a
candidate for pruning.
